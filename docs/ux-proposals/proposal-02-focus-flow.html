Design 02: Focus Flow Workspace

A calm, guided flow that reduces cognitive load by separating context setup, execution, and review as explicit steps.

Design Goals

  • Turn one long operations page into predictable "flow lanes".
  • Make default state obvious: what should user do next?
  • Improve readability on both dark and light themes.

Primary Journey

1. Context
Session title, provider, model, purpose, resume ID.
2. Execute
Prompt + attachment composer, delegate action, active run state.
3. Observe
Terminal stream + queue timeline with retry/continue affordances.
4. Maintain
Schedules + local changes + session settings/danger zone.

Component Delta from Current App

  • Convert queue list to timeline cards with prominent timestamps.
  • Move schedule creation into a side-sheet with progressive fields.
  • Collapse low-frequency controls (raw terminal input, session delete) behind "Advanced".
  • Add a sticky "Next recommended action" helper row based on session state.
