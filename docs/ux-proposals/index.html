UX Review + 3 New Design Directions

This package reviews the current Orchestrator UX and proposes three implementable visual/interaction directions with icon systems.

Current Feature + Implementation Review

  • Information architecture: two-column shell (session list + main pane) with heavy stacked cards in the main pane.
  • Core strengths: robust task queue controls, schedule CRUD, live tmux stream, file-change diff panel, provider session continuity.
  • Main UX pressure points: high cognitive load in one vertical page, low hierarchy between "monitoring" vs "authoring", and too many similarly styled actions.
  • Mobile behavior: sidebar shifts to horizontal scroll but primary operations remain dense and form-heavy.
  • Iconography baseline: functional mono-line icons are present, but semantic grouping (Run, Queue, Session, Safety) is not visually distinct.
