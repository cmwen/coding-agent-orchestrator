This version removes the device chrome entirely and instead shows the new interaction model as a real responsive product surface. Desktop behavior Resizable session rail, persistent workspace tabs, and clear handoff between delegate, terminal, queue, changes, and schedules.
Mobile behavior Lane-based home board, bottom navigation, and a terminal drawer view that keeps queue, delete actions, and change triage reachable on a smaller screen.
Feature coverage Desktop command palette, model and execution mode selection, file attachments, SSE reconnect states, retry flow, diff review, schedule editing, and manual schedule runs.

    What this design now makes obvious

    • Desktop actions become faster without crowding the layout. A command palette adds keyboard-first access to create session, jump tabs, retry jobs, and open schedule actions while keeping the main workspace visually calm.
    • Queue and changes are part of the same workflow. Users can move from prompt to output to diff review without losing the current session or selected job, and on mobile the Home view now clearly acts as the task queue board.
    • Schedules feel like automation, not a side panel. Recurring work gets a dedicated planning view, run history, pause/resume controls, and explicit delivery/status details.
